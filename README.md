# 🖩 Simple Calculator

A basic calculator program written in C that can perform addition, subtraction, multiplication, and division.

## 🔹 Features
- ➕ Addition  
- ➖ Subtraction  
- ✖ Multiplication  
- ➗ Division  

## 🛠 Tech Used
- C Programming

## 🚀 How to Run
1. Download the `calculator.c` file  
2. Compile using `gcc calculator.c -o calculator`  
3. Run using `./calculator`
